# Lab 07 - Security, Compliance, and Cost Optimization

## Objectives

- Review AWS security posture services.
- Inspect compliance and configuration findings.
- Use cost tools to identify waste.
- Prepare practical optimization recommendations.

## Scenario

Operations teams must keep workloads secure and cost aware. You will inspect common AWS services used for security signals, compliance tracking, and cost management.

## Steps

1. Open IAM Access Analyzer and review available findings.
2. Open AWS KMS and review key types.
3. Identify where customer managed keys may be required.
4. Open GuardDuty and review detector concepts.
5. Open Security Hub and review security standards.
6. Open Amazon Inspector and review vulnerability scanning coverage.
7. Open AWS Config and review rules and resource history if enabled.
8. Open Trusted Advisor and review available checks.
9. Open Cost Explorer.
10. Review daily service costs for the current month.
11. Identify any unexpected cost spikes.
12. Open AWS Budgets and confirm budget alerts.
13. Open Compute Optimizer and review rightsizing recommendations if available.
14. Review tags used for cost allocation.
15. Write three recommendations:
    - One security improvement.
    - One compliance improvement.
    - One cost optimization action.

## Validation

- You can name the purpose of GuardDuty, Security Hub, Inspector, and Config.
- You can explain why tags matter for cost allocation.
- You can find cost trends in Cost Explorer.
- You can make optimization recommendations based on evidence.

## Cleanup

Disable trial features or sample configurations only if your trainer instructs you to do so.

## Review Questions

1. How are GuardDuty and Security Hub different?
2. What does AWS Config help you prove?
3. Why is least privilege important for operations?
4. What is the risk of optimizing cost without checking resilience?
